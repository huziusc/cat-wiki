模板 A：标准导航卡片（4-6 项）

用于: medical, daily-care, acquisition, diet-staple/index

格式

规则：

  • 每张卡片一个 > blockquote 段落
  • 卡片间用空行分隔（Obsidian 渲染为独立卡片）
  • 每张卡片：> ### [emoji] [Title](link) + > one-liner description
  • Link 使用相对 wikilink 或 markdown link（保持与当前 table 一致的路径风格）

模板 B：紧凑卡片（6+ 项）

用于: illness/index (10 项)

格式

规则：

  • 每行 2 个卡片，用 | 分隔（同一 blockquote 内）
  • 每张卡片：> **[Title](link)** — one-liner
  • 第三行起根据条目数调整（末尾单卡片也可单独一行）

备选（更紧凑）：

如果一条 blockquote 放 10 个入口过密，折中为 2 行 × 5。

实施检查清单

每个页面的改动步骤：

  • 定位 ## 子分类 section
  • 将 <table> 替换为对应模板的 quote-block 卡片
  • 确认 wikilink 路径与原 table 一致
  • 检查是否有重复内容（如 acquisition 的品种参考）
  • 保留 ## 新手必读 和 ## 相关链接 不动
  • 保留内部内容型 table 不动（疫苗对比、投喂规则等）
  • 确认 emoji 与卡片内容匹配

通用规则

  1. 不改 frontmatter
  2. 不改非 ## 子分类 的 section（「新手必读」「相关链接」「核心原则」等全部保留）
  3. wikilink 格式保持与原来一致（原来用 [text](link) 就用 markdown link，原来用 [[link]] 就用 wikilink）
  4. emoji 选配原则：功能清晰 > 装饰性。选 macOS/iOS 广泛支持的 emoji。
  5. 描述文案：从原 table 的「一句话描述」列提取，可微调但不重写。
