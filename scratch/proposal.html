Priority 1：修复死链与结构错误（必须处理）

P1.1 创建 preparation.md

范围：新建 1 文件
影响：修复 6 个 404 死链，恢复新手路径 Stage 2
内容大纲（建议）：

  • 物品清单（猫砂盆、食碗、水碗、猫抓板、猫爬架、运输笼等）
  • 环境布置（隔离区、安全区、猫砂位置、食水位置）
  • 文件准备（疫苗记录、血统证书、保险购买时机）
  • 时间安排（接猫前 1 周/3 天/1 天的 check 清单）
  • 常见误区

Trade-off: 无。纯粹补漏，不创建子任务。

P1.2 移动 breed-exotic.md → entities/

范围：移动 1 文件 + 更新所有 wikilink 引用
影响：修正 entity/concept 边界，品种页统一归入 entities/
实施：

  • 移动 concepts/acquisition/breed-exotic.md → entities/breed-exotic.md
  • frontmatter 中 type: entity → type: breed
  • 更新所有 [[concepts/acquisition/breed-exotic]] → [[entities/breed-exotic]]
  • 影响文件：newbie-guide.md, concepts/acquisition.md, concepts/medical.md, concepts/acquisition/cattery.md 等

Trade-off: 需要批量更新 ~6-8 个文件的 wikilink，一次性操作。之前 t_fcf1dab6 (Bug3) 只更新了 wikilink 但未实际移动文件——本次应同时做。

Priority 3：对齐 SCHEMA.md 与实际实现（后续更新）

P3.1 更新 SCHEMA.md 用药模块树

原因：实现（concepts/medication-guide/ 目录）比 SCHEMA 的扁平化设计更合理。将 hub/kid/safety 三个指南页归组在 medication-guide/ 目录下是好的组织方式，避免根目录过度扁平。

建议：修改 SCHEMA 的 💊 用药 部分树结构：

P3.2 更新 SCHEMA frontmatter 中 type 合法值

已有 homepage 类型被 index.md 使用，需要列入。

P3.3 统一药物 frontmatter 字段名

当前实体实现使用 category: medication + drug_class/emergency_level，SCHEMA 定义 type: medication + medication_type/active_ingredient/administration/prescription。

建议：采用实现版本并更新 SCHEMA。理由：

  • drug_class 比 medication_type 更精确（抗生素/驱虫药 vs topical-flea）
  • emergency_level (🔴需就医/🟡需就医/🟢家庭备用) 比 prescription: true/false 信息量更大
  • 实现字段已经过 spec + 模板设计（t_860df2f5），成熟度更高

P3.4 标记 methods/templates 为「待建」

Priority 4：导航深度优化（可选改进）

P4.1 在 experienced.md 添加快速锚点

当前 experienced 有两张卡片（医疗健康 / 日常养育）→ 进入各自的 hub 页 → 再选择子分类。对高频查询可加 “⚡快速入口” 直达表格。

影响：减少老手路径 1 层点击（4 层 → 3 层）。
Trade-off：experienced.md 增加 ~4 行表格。维护成本低。

P4.2 diet-staple.md 可扁平化（备选方案）

将 6 个 staple 子类型的核心信息（一句话推荐+链接）合并到 diet-staple.md 页内，子页保留详情。
路径：index → experienced → daily-care → diet → diet-staple (含 dry/canned 摘要)
Trade-off：diet-staple.md 变长（~1 屏），但减少 1 层导航。个人判断不推荐扁平化——6 个子页各自包含充足内容（品牌推荐、投喂规则、保存建议），强行压缩会损失信息密度。

建议：下次编辑任何现有页面时顺手补充 life_stage 和 multi_cat 字段。不需要批量一次性操作，但应作为编辑惯例写入 SCHEMA。

scoped within D8 但未实施：

无需立即处理，但 SCHEMA 应标注”待建”。
