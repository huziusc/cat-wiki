Cat Wiki 视觉增强方案

创建: 2026-05-22 | 基于: Notion + Mintlify 融合设计语言 约束: 仅输出设计方案，不修改 content vault

一、设计哲学：Warm Precision（温暖的精确）

Cat Wiki 的核心身份：猫咪养育知识库。它既不是冷峻的开发工具（不适合 Linear），也不是企业 SaaS（不适合 Stripe）。它的读者是猫家长——需要信任感、可读性、以及一丝暖意。

设计融合策略

来源借鉴什么为何借鉴
Mintlify空气感留白、全圆角按钮(9999px)、卡片大圆角(16px)、低密度内容布局文档型站点 → 阅读舒适度为第一优先级
Notion暖灰中性色系（#f6f5f4 warm white）、超薄边框(5% opacity)、微阴影层叠温暖的「纸感」而非冰冷的「玻璃感」
Cat Wiki 独有品牌色琥珀/奶油（#E8985E），猫爪圆角语言辨识度 + 情感连接

核心原则

  1. 阅读优先 — 文字密度降低 30%+，关键信息前置，详情可折叠
  2. 卡片即导航 — 首页/老手入口全部卡片化，icon + 一句话描述 + 链接
  3. 图片讲故事 — 品种照、症状示意、药品包装——图片承担信息传递，非纯装饰
  4. 呼吸感 — 段落间距 >=24px，卡片 padding >=20px，拒绝「挤」

阴影哲学: Mintlify 的「几乎没阴影」路线 — 深度通过圆角和边框表达，阴影只做最轻微的 lift。

4.3 图片来源

来源用途获取方式
胡胡自摄科科/顺毛/棒棒的照片 — 品种页（英短、加菲）直接嵌入
Wikipedia Commons品种标准照、解剖图CC-BY-SA，标注出处
兽医教科书插图（公开领域）疾病症状示意需确认版权
药品官网药品包装合理使用，标注来源
Unsplash / Pexels通用猫咪插画、装饰图CC0，无需标注

4.4 图片规范

  • 格式：照片用 WebP（体积小），示意图用 PNG（清晰）
  • 尺寸：品种照 800×600，示意图 600×400，药品包装 400×300
  • alt text：必填，中文描述（「英短蓝猫 —— 圆脸铜眼、灰蓝色短毛」）
  • 标注：图片下方 caption 标注来源和许可（*图片来源：Wikipedia Commons, CC-BY-SA 4.0*）

五、文字密度降低策略

5.1 当前问题

以 entities/breeds/british-shorthair.md 为例（149 行，~10KB），首屏需要滚动 3 屏才能看完标题+概述+健康风险。关键信息（「公猫 HCM 患病率 20.4%」）被埋在深层表格中。

5.2 解决方案：TL;DR + 折叠详情

每页在 H1 下方增加 一句话总结（blockquote callout），让读者在首屏就能理解页面核心：

六、一致性策略

6.1 与 Task 2（子分类卡片）统一

Task 2 创建的子分类卡片（如 medical.md 的 5 个子分类表）应与首页卡片使用相同视觉语言：

  • 相同圆角（16px）
  • 相同边框（rgba(0,0,0,0.06)）
  • 相同 hover 效果（琥珀淡底 + 上浮）
  • icon + 描述 + 链接的三段式布局

七、实现优先级 (Implementation Roadmap)

优先级任务工作量依赖
🔴 P0custom.scss 写入全局样式变量 + 卡片基类小无

🟠 P1老手入口页卡片化（experienced.md）小P0
🟡 P2疾病页加 TL;DR + 症状示意图（FLUTD、口腔）中图片资源

🟢 P3概念页文字密度降低（全文批量 TL;DR）大P0
🟢 P3图片资源库建立（_attachments/）中图片采集

八、风险与约束

  1. Quartz callout 折叠兼容性 — Quartz 对 Obsidian callout 语法的支持有限。需在本地构建测试 [!note]- 折叠语法。
  2. 图片托管 — Quartz 默认将 _attachments/ 下的图片复制到 public/ 输出。需确认路径解析（相对路径 vs 绝对路径 vs wikilink ![[image]]）。
  3. 中文字体渲染 — 当前 Quartz 使用 fontOrigin: "local" + system-ui stack，中文兼容性已测试通过。
  4. 不修改 content vault — 此方案仅输出设计提案和 mockup。实际修改需胡胡批准后另行安排。

本方案基于对当前 wiki（78 个 .md 文件、SCHEMA.md、Quartz v4 构建）的完整审计。设计参考：Mintlify（文档站点空气感）、Notion（暖灰中性色系）、Linear（层级精确性）。
