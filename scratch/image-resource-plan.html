三、图片来源详解

来源 1: 胡胡自摄（最优先）

已拥有：科科（加菲/异短，橘色）、顺毛（英短蓝猫）、棒棒（混血）

用途猫拍摄建议
英短品种标准照顺毛自然光、正面/侧面各一张、背景干净
加菲品种标准照科科突出扁脸特征、侧面展示面部结构
Hero 插画替代三猫合照温馨构图，可用于首页装饰

来源 2: Unsplash / Pexels（CC0，无需标注）

搜索关键词：

  • british shorthair cat → 英短品种照
  • ragdoll cat → 布偶品种照
  • cat veterinarian → 医疗插画
  • cat illustration → 装饰插画

CC0 许可：可自由使用、修改、分发，无需署名。但建议在图片 caption 中标注「图片来源：Unsplash」以示透明。

来源 3: Wikipedia Commons（CC-BY / CC-BY-SA）

搜索：https://commons.wikimedia.org/

关键词：

  • Felis catus anatomy → 解剖图
  • cat dental disease → 牙科图
  • British Shorthair → 品种照

许可标注要求：CC-BY 和 CC-BY-SA 需要署名。在图片下方 caption 中标注：

*图片来源：Wikimedia Commons, [作者名], CC-BY-SA 4.0*

来源 4: 药品官网（合理使用）

药品包装图片用于教育目的，属于合理使用范畴。标注来源：

*图片来源：[药品官网名]，仅用于教育参考*

四、图片嵌入方法

4.1 Markdown 嵌入（推荐）

Quartz 会解析相对路径，将图片复制到 public/ 并调整路径。

4.2 Wikilink 嵌入

注意：Wikilink 图片嵌入在 Quartz 中可能需要自定义 transformer 或使用相对路径。优先使用相对路径 Markdown 语法，兼容性最好。

4.3 图片规范

要求值
最大宽度800px（品种照）/ 600px（示意图）/ 400px（药品）
格式WebP（照片）/ PNG（示意图/图表）
文件大小< 200KB
alt text必填，中文（描述图片内容，用于无障碍和 SEO）
caption推荐，标注来源、许可、拍摄者

六、注意事项

  1. 版权：CC-BY 图片必须署名；Unsplash/Pexels 的 CC0 图片无需署名但建议标注以示透明。
  2. 加载性能：图片必须经过压缩（WebP, <200KB）。首页 Hero 图片过大是常见性能杀手。
  3. 响应式：图片使用 HTML <img> 的 max-width: 100% 或 CSS 的 object-fit 保证在手机上不变形。Quartz 默认对 markdown 图片做了响应式处理。
  4. 回退：如果图片加载失败，alt text 会显示。确保每张图片的 alt text 是描述性的（不只是「品种照」，而是「英短蓝猫 — 圆脸铜眼、灰蓝色短毛」）。
